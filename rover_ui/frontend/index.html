Navigation

—

Navigate to detection projects the live fused target (camera bearing + radar range) onto the map and drives to 2 m below it. Auto re-dispatches whenever a stable target appears. Follow tracks the live target continuously and re-plans the moment it moves, overriding the navigation in progress. Speed caps the drive speed (applies live, even mid-move). Clicking the map navigates to a manual target instead.

Pose anchor

Place the rover physically on its start cell (—, facing the top of the map), then re-anchor so map position matches reality.

Drive hold to move · release to stop

—

Drives continuously at the set speed while held, with T265 heading-hold. A 0.5 s dead-man stops the rover if the page/network drops mid-press. Disabled while a navigation is running. (Also capped by the Navigation Speed above.)
